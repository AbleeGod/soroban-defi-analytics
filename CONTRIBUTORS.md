## How to be added

You are automatically eligible for this file once any of the following
is merged or accepted:

- A pull request with code, tests, or documentation changes.
- A detailed bug report that leads to a confirmed fix.
- A design contribution (mockups, accessibility audit, etc.).

Maintainers update this file with every release. If your contribution
was missed, open a PR adding yourself — we'll merge it promptly.
